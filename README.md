FwsDoctrineAuth
===============

Docs available [online](https://www.freedomwebservices.net/laminas/fws-doctrine-auth).

Laminas Doctrine Authentication Module.
This module uses email/username and password combination to keep unwanted users out of your websites more sensitive areas. 
This module also includes email, sms and app based two factor authentication for that extra layer of security.

This module requires Doctrine Module and uses Doctrine ORM.

Note: as of version 0.4.0 the encryption/decryption has been removed and replaced with 
my new Doctrine Crypt module. Please [see here](https://www.freedomwebservices.net/laminas/fws-doctrine-crypt) for more
information.
